                        KEY DESIGN DECISIONS
═══════════════════════════════════════════════════════════════════════════════

✅ DUAL FORMAT PRESERVATION
   - Both LilyPond and TinyNotation coexist in the same file
   - Visual side-by-side comparison for educational purposes
   - No loss of original LilyPond notation

✅ PRIORITY SYSTEM
   - build_score_data() > SOURCE_MELODY_TINY > SOURCE_MELODY_LILY > build_part()
   - first.py uses build_score_data() so it processes regardless of snippets
   - If build_score_data() were removed, SOURCE_MELODY_TINY would be processed

✅ SNIPPET ORGANIZATION
   - MELODY_SNIPPETS: Collection of alternative melodies
   - HARMONY_SNIPPETS: Collection of harmony patterns
   - DEFAULT_HARMONY: Selected harmony for current composition
   - Easy to swap patterns without editing core logic

✅ TWO-STAVE OUTPUT
   - Melody: Treble clef (top staff)
   - Harmony: Bass clef (bottom staff, transposed -12 semitones)
   - Metadata preserved on both staves

✅ MUSIC21 TRANSFORMATIONS
   - Identity/copy: Preserve original melody
   - Transpose: Shift harmony to bass range
   - (Optional) Chordify: Combine into vertical chords
   - (Optional) Inversion: Mirror melodic contours
   - Easy to add more transformations (augmentation, retrograde, etc.)
