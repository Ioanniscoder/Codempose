PIPELINE PRIORITY SYSTEM:

When run_pipeline_from_file() is called, it checks in this order:

    Priority 1: build_score_data()  ◄─── first.py uses THIS
    Priority 2: SOURCE_MELODY_TINY  ◄─── Will be used if build_score_data() removed
    Priority 3: SOURCE_MELODY_LILY  ◄─── Fallback option
    Priority 4: build_part()        ◄─── Lowest priority

Because first.py has build_score_data(), it processes regardless of whether
SOURCE_MELODY_TINY exists. The toggle controls whether TINY gets generated,
but doesn't affect processing when build_score_data() is present.
