## Quick Start Guide

### 1. Extract the Archive

```bash
tar -xzf codempose_complete_with_harmonic_intelligence.tar.gz
cd codempose/
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

**Required packages:**
- music21
- abjad
- python-ly (for LilyPond parsing)

### 3. Run a Basic Study

```bash
python3 first.py
# Generates: outputs/first.pdf, first.ly, first.musicxml, first.midi
```

### 4. Try Multi-Voice

```bash
python3 tenth.py
# Generates: Four-voice SATB score
```

### 5. Test Harmonic Intelligence

```bash
# Structural analysis
python3 fifteenth.py

# Basic harmonization
python3 sixteenth.py

# Advanced harmonization
python3 seventeenth.py
```

### 6. View Outputs

```bash
# View PDFs
xdg-open outputs/sixteenth.pdf
xdg-open outputs/seventeenth.pdf

# Play MIDI
timidity outputs/sixteenth.midi

# Import to MuseScore
musescore outputs/sixteenth.musicxml
```

## System Architecture

### Data Flow

```
LilyPond Input
    ↓
[lilypond_parser.py]
    ↓
Canonical Event Format
    ↓
[music_data.py: data_to_part()]
    ↓
music21 Objects
    ↓ (NEW!)
[harmonic_analysis.py]
[harmonic_engine.py]
    ↓
Enhanced Score
    ↓
[music_data.py: part_to_data()]
    ↓
Canonical Event Format
    ↓
[Export Pipeline]
    ↓
PDF / MusicXML / MIDI / LilyPond
```

### Module Dependencies

**Core Pipeline:**
- `project_template.py` → Main orchestrator
- `lilypond_parser.py` → Input parsing
- `music_data.py` → Data conversion
- `score_builder.py` → Output generation
