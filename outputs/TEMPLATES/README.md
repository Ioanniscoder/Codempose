# CODEMPOSE TEMPLATES

This directory contains templates and examples for creating powerful compositions using the Codempose framework.

## Files in This Directory

### 📝 study_template.py
Basic template for creating new study files with the four-station workflow.

**Use this when:** You want to create a simple composition with basic transformations.

### 🎼 station4_music21_examples.py
**Comprehensive library of music21 transformations for Station 4.**

**This is the key file for understanding Station 4's full potential!**

Contains ready-to-use examples of:
- **Pitch Transformations**: transpose, invert, retrograde, retrograde-inversion
- **Rhythm Transformations**: augmentation, diminution, displacement, swing
- **Harmonic Analysis**: chord extraction, voicing generation
- **Contrapuntal Techniques**: canon, invertible counterpoint, augmentation canon
- **Algorithmic Composition**: sequences, fragmentation, motivic development
- **Advanced Analysis**: contour extraction, rhythmic density, key detection

## Station 4 Power: What Music21 Can Do

### Category 1: Pitch Transformations
Transform melodies while preserving rhythm:
- `example_transpose_diatonic()` - Stay in key
- `example_transpose_chromatic()` - Modulate freely
- `example_inversion_mirror()` - Mirror around a pitch
- `example_retrograde()` - Play backwards (crab motion)
- `example_retrograde_inversion()` - Combine both

### Category 2: Rhythm Transformations
Manipulate time and rhythm:
- `example_augmentation()` - Slow down (2x, 4x, etc.)
- `example_diminution()` - Speed up (0.5x, 0.25x, etc.)
- `example_rhythmic_displacement()` - Offset in time

### Category 3: Harmonic Analysis
Extract and generate harmony:

## Complete Example: Fugue Generator

```python
def build_score_data():
    from outputs.TEMPLATES.station4_music21_examples import example_fugue_exposition
    
    # Your fugue subject (4-8 notes work well)
    SUBJECT_LILY = r"\relative c' { c8 d e f | g4 f8 e | d4 c4 | }"
    
    subject_data = parse_lilypond_to_data(SUBJECT_LILY, 'Subject')
    subject = subject_data['parts']['Subject']
    
    voice_lookup = {'SUBJECT': subject}
    metadata = {
        'title': 'Fugue in C Major',
        'composer': 'Generated by Codempose',
        'original_snippets': {'SUBJECT_LILY': SUBJECT_LILY}
    }
    
    # Generate complete fugue exposition
    fugue = example_fugue_exposition(subject, voice_lookup, metadata)
    
    # Build 4-voice fugue
    return {
        'metadata': metadata,
        'parts': {
            'Soprano': fugue['answer'],           # Answer in dominant
            'Alto': fugue['countersubject'],      # Inverted counterpoint
            'Tenor': fugue['subject'],            # Original subject
            'Bass': fugue['subject_augmented']    # Augmented for stretto
        }
    }
```

## Tips for Station 4

### 1. Start with Simple Transformations
Begin with basic transpose and invert, then add complexity.

### 2. Use Documentation
Every transformation automatically documents itself when you use `register_and_document_voice()`.

### 3. Chain Transformations
```python
# Transpose, then invert, then augment
transposed = transpose_events(theme, 5)
inverted = invert_events(transposed, 'c4')
final = example_augmentation(inverted, factor=2.0)
```

### 4. Analyze Before Generating
Use analysis functions to understand your material before transforming it.

### 5. Mix Station 3 and Station 4
Use programmatic transformations to create voices, then arrange them with Station 3 shorthand:

```python
# Generate voices programmatically
soprano_inv = example_inversion_mirror(soprano, 'c4', voice_lookup, metadata)
alto_aug = example_augmentation(alto, 2.0, voice_lookup, metadata)

# Then use shorthand to arrange
VOICE_ASSIGNMENTS = {
    'Melody': {
        'Soprano': 'SOPRANO + SOPRANO_INV',  # Original + inverted
        'Alto': 'ALTO_AUG * 2'               # Augmented, repeated
    }
}
```

## Music21 Integration

All these examples use music21 under the hood. The Codempose framework:
1. Parses LilyPond → canonical events
2. Converts events → music21 Part (with `data_to_part()`)
3. Applies music21 transformations
4. Extracts back to canonical events (with `extract_data_from_part()`)
5. Documents as LilyPond snippets
6. Generates all output formats

## Documentation Output

Every programmatic voice you create gets documented in the `.ly` file:

```lilypond
% ========================================
% PROGRAMMATIC VOICES (Station 4)
% ========================================
%
% CANON_FOLLOWER_7:
%   \relative c' { \time 4/4 \key c \major r1 g'4 a'8 b'8... }
%
% FUGUE_ANSWER:
%   \relative c' { \time 4/4 \key c \major g4 a8 b8 c'4 d'4... }
```

These snippets are **copy-paste ready** and can be used in future compositions!
