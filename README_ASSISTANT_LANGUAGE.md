Preferred assistant language
============================

This repository prefers English for automated assistant responses and project
documentation. If you are interacting with an AI assistant (Copilot Chat, chat
bots, etc.), please request responses in English by default.

Suggested one-liner to use in chat:

    Please respond in English from now on.

This file is informational only and does not force behavior — it documents the
project's preference for human collaborators and automated tools.
