│  def build_score_data():                                                     │
│      # Parse LilyPond                                                        │

│      # Convert to music21.Part                                               │
│      theme_part = data_to_part(theme_data['parts']['Theme'], metadata)      │
│                                                                              │

│      # Apply music21 functions                                               │

│      events = extract_data_from_part(transformed)                           │
│                                                                              │
│      return {'metadata': metadata, 'parts': {'Melody': events}}             │

═══════════════════════════════════════════════════════════════════════════════
                              BEST PRACTICES
═══════════════════════════════════════════════════════════════════════════════

✓ START SIMPLE (Station 1)
  └─ Use LilyPond notation for initial composition
  
✓ PROMOTE AS NEEDED
  └─ Only add complexity when simple approach insufficient
  
✓ MIX STATIONS FREELY (Hybrid Approach)
  ├─ Complex voices → Station 4 (full control)
  ├─ Simple voices → Station 3 (brevity)
  └─ Use both in same composition!
  
✓ DOCUMENT PROGRAMMATIC VOICES
  └─ Use register_and_document_voice() to capture results
  
✓ CLOSE THE LOOP (Feedback)
  ├─ Generate → Document → Study
  └─ Copy results back to Station 1 for refinement

✗ DON'T OVER-ENGINEER
  └─ Avoid Station 4 for simple repetition (use Station 3)
  
✗ DON'T FORCE SHORTHAND
  └─ Use Station 4 for complex algorithms (shorthand has limits)
